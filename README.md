# TPPS website (Three Phase Power System Est.)

First draft of the bilingual (English / Arabic) website for TPPS, an LV, MV and HV electrical
contractor in Jeddah. Built on the Energy Basics draft (same structure, components and hash routing),
restyled to the TPPS Brand Guidelines (Nov. 2025).

Preview: GitHub Pages at https://niamhqmahon-rgb.github.io/TPPS/ (once enabled for the
`claude/lucid-ptolemy-kh0c2q` branch), or locally with `python3 -m http.server 8000` in the repo root, then open http://localhost:8000

See `CLAUDE.md` for structure, conventions and the open list.
